# btop

btop (btop4win on Windows) in the eight Zacess themes, so the system monitor matches the terminal
around it.

## What is here

| Path | What it is |
| --- | --- |
| `themes/zacess-<theme>.theme` | One btop theme per Zacess theme, generated by `terminal/terminal/scripts/build-themes.py` from `palette/zacess.json`. Do not edit by hand. |

## How a theme is chosen

`zt` sets btop's theme on every switch:

| System | Where btop reads its settings | What `zt` does |
| --- | --- | --- |
| macOS and Linux | `~/.config/btop/btop.conf` and `~/.config/btop/themes` | Links all eight themes into `themes`, points `color_theme` at the current one and sets `theme_background = True` |
| Windows | `btop.conf` and `themes` beside `btop4win.exe` (under `WinGet\Packages` for a winget install, which links it on the PATH as `btop`) | The same, in the folder beside the exe |

Only `color_theme` and `theme_background` are rewritten, so every other btop setting stays as it
is. A missing `btop.conf` is started with just those two keys. btop picks the theme up at its next
start. Every Zacess theme also appears under Options, Color theme, beside btop's own themes, and
the built-in `TTY` theme stays available as a fallback that uses the terminal's own colours.

## Colours

Every text colour is the theme's foreground, its muted text or one of its terminal colours, which
the generator holds to 4.5:1 or more on the background, so btop keeps the same contrast as the
terminal. The four boxes (CPU, memory, network and processes) each keep their own colour and their
title, so they are told apart by more than colour.

## Install

| System | Command |
| --- | --- |
| macOS | `brew install btop` (in `shell/mac/Brewfile`) |
| Linux | Installed by `setup/linux-bootstrap` |
| Windows | `winget install --id aristocratos.btop4win -e` (in `setup/windows-bootstrap/packages/winget.json`) |
