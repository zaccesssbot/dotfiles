# windows/cmd/

Command Prompt (`cmd.exe`) set up to match the PowerShell profile as far as it can without any add-on: the same welcome banner, a coloured prompt, the PowerShell aliases and short functions as doskey macros and the `zt` theme command.

| File | What it does |
| --- | --- |
| `autorun.cmd` | Start-up script. Runs only in an interactive window: sets `DOTFILES`, loads the macros, sets the prompt and prints the banner |
| `macros.doskey` | One doskey macro per PowerShell alias or short function that is a plain command line, written by [`scripts/build-cmd-macros.py`](../../scripts/build-cmd-macros.py) |
| `banner.ps1` | The PowerShell profile's welcome banner, with Command Prompt as the shell |

`zt.cmd` and `zacess-theme.cmd` live next to the PowerShell `zt` in [`windows/scripts/`](../scripts/), which the bootstrap puts on the user `PATH`, so `zt deep-light` works in Command Prompt as well.

## How it starts

`cmd.exe` runs the command in the `AutoRun` value under `HKCU\Software\Microsoft\Command Processor` every time it starts. The Windows bootstrap sets it to `call "<this folder>\autorun.cmd"`, keeping any earlier value after it with `&` and saving that earlier value first. Scripts and programs start `cmd.exe` with `/c` or `/k` too, so `autorun.cmd` reads `%CMDCMDLINE%` and stops straight away for those: only a window someone types in gets the macros, prompt and banner.

To turn it off, delete the value or set it back to the saved one:

```bat
reg delete "HKCU\Software\Microsoft\Command Processor" /v AutoRun /f
```

## Colours

The prompt and banner use ANSI escape codes for the terminal's 16 colour slots (`$E[36m` is the cyan slot, `$E[33m` the yellow one), never fixed colours. Whatever theme the terminal is on, dark or light, Zacess or not, the prompt takes that theme's own cyan, yellow and green, so it reads as well as everything else in the window. Windows Terminal shows them as they are; the older console host needs `VirtualTerminalLevel` set to `1` under `HKCU\Console`, which the bootstrap also sets.

The prompt is `user@machine` in cyan, the folder in yellow, then `>` in green on its own line. The banner costs one short PowerShell start; set `DOTFILES_NO_BANNER` to skip it, the same variable the PowerShell profile reads.

## Macros

A macro works only at the prompt, not inside a batch file. It takes its arguments as `$1` to `$9` and `$*`. [`scripts/build-cmd-macros.py`](../../scripts/build-cmd-macros.py) turns a PowerShell function into a macro when its body is a plain command line: an external program and its arguments, `Set-Location` on a fixed folder (`cd /d`) or `Start-Process` on a web address (`start`). Run it again after changing a topic file. `doskey /macros` lists what is loaded.
